# 文章与作品更新

## 内容来源

生产文章来自原 `content/blog/*.md` 与原渲染器；作品、工具及收藏来自同服务 `content/site-catalog.json`。本仓库不保存实时内容台账或发布凭据。`examples/` 是公开样例与测试夹具，不能拿它覆盖生产目录。

文章继续由既有 blog 工具创建、修改、发布或撤回。只有明确 `published` 的正文进入公开 JSON、SSR、搜索与翻译关系。中英用同一 `translationKey` 或相同 stem 的 `-zh/-en` 配对；缺译文不生成链接，补译文不改变原首发日期。

现有每日私人审稿流程保持：中英标题和正文齐全后送审，批准绑定两份原文与配图；发布前重新检查版本。每次审稿消息默认二十篇，余稿保留，这只是消息容量。具体执行与账号由原私有发布环境管理，不复制到本仓库。

## 新作品与修订

使用原 `site_catalog_get` 读取目录及 revision。准备增量后，用 `site_catalog_update` 携带现有批准引用与公开原作地址，先 `dry_run=true`，检查通过再应用。冲突时重新读取，不用旧目录覆盖并行更新。

作品至少需要稳定 `id`、`title`、中英 `zh/en` 简介、公开 HTTPS 原作地址、已有 `kind` 与明确 `status`。已公开不等于已完成；设计中的产品保留自身状态描述。`featuredRank` 控制精选，普通作品自然进入目录、筛选、搜索和详情；`tool` 决定是否派生到工具目录，无需维护第二张作品卡。

项目关联文章使用 `translationKey`。镜像平台不重复生成项目。撤回文章会从公开配对和作品关联中消失。

## 摘要与回读

目录里同语言 `articleMetadata[slug].summary` 优先于 Markdown 摘要。改正文时同步更新该摘要，或显式写空字符串清除覆盖；然后回读 `/static/content.json` 和对应正文，核对标题、摘要、正文、中英链接及原文 URL 后登记原发布回执。

正文先由原 Markdown 渲染器生成，再统一净化 HTML。日期使用实际首发/修订日期。单语旧稿不会被界面语言自动翻译。

## 开发与测试

`npm run validate` 校验公开样例。`scripts/import-content.mjs` 仅供样例迁移和隔离验证，不能作为日常线上发布入口。开发服务器支持：

```sh
python3 integration/preview_server.py --public-web --port 9567
python3 integration/preview_server.py --catalog /private/path/catalog.json --blog-dir /private/path/blog --port 9567
```

第二种只读本地隔离内容，素材放在仓库之外。不要把未审稿件、配置或凭据写入 `static/`。

## 开源雷达栏目

`/radar` 从同一公开文章集合读取 `oss-radar-` 开头的已发布稿件，按翻译关系合并成一期，按首发日期排列；不维护第二份日刊目录。发布和撤回继续走原文章工具，新一期自然进入最新一期、搜索和往期归档。中英内容沿用全站语言选择与缺译提示。

十方志默认列表单独展示其他文章；旧 `/blog/oss-radar-*` 正文地址和显式系列筛选仍可访问。雷达项目速览从正文标题及“一句话 / In one line”抽取，不另外编造摘要；项目链接直达原文锚点。页面动效只用于导航，关闭动态或系统减少动态时直接切换，滚动方式保持连续。

首页「最近写了」独立选择最近三篇已发布普通文章，开源雷达另以最新一期入口展示；筛选在语言配对后执行，两类内容互不占用名额，雷达连续更新也不会挤走文章。

全站卡片共享入场扫光：现有工具、作品、文章、雷达和收藏卡片统一接入；新增卡面可标记 `data-surface`。卡片首次进入视野时播放一次，页面切换后延至揭幕后，离开页面会清理观察器和临时层。关闭动态或系统减少动态时停用；原证书悬停和大图流光独立保留。

文章入口可悬停预览已发布正文的片段与前四个章节，沿用当前语言版本；不生成第二份摘要，不显示草稿。鼠标预览以渐显浮起入场，位置通过按帧缓动跟随；鼠标模式浮卡不参与命中测试，持续跟随且避开指针，点击透传原文章入口，离开渐隐；键盘模式在原文章入口按Enter阅读，关闭动态时取消位置缓动。预览只显示分类、时长、正文节选及目录，不重复文章标题、不放按钮；键盘聚焦可看，Esc关闭，在原文章入口按Enter阅读全文。仅精细指针和宽屏启用，手机保留直接点开文章。退出路由时清理事件、定时器和弹层。

文章正文不再保留侧栏目录。至少三个主章节时使用底部折叠目录，显示当前章节与阅读进度；子章节随正文层级缩进。中英共用渲染规则，不维护第二份目录。目录在正文进入视野后出现、正文结束后隐藏，支持键盘、Esc、原锚点及减少动态。

首页文字与作品保持原有顺序和连续滚动；宽屏动态模式下仅在交界处作局部覆盖，作品与相关文章按原关联字段衔接。作品详情同一展示画面随滚动收向左侧（终态占58%宽、保留原高度和字号，右侧资料占余下空间），原资料和相关文章从右侧进入；不另存作品文案。窄屏和关闭/减少动态时回到原顺序布局，不增加滚动轨道或整屏吸附。


## 公开内容统计

`static/analytics.js`仅在正式公开域名与明确公开路由启用；开发预览、私有页面、Do Not Track及本浏览器排除开关不发送。页面切换按路径与语言去重。仅记录页面、文章入口曝光/点击、前台有效阅读30秒、至少阅读15秒后的50%/90%正文深度、作品/源码/RSS/回应入口点击；点击不代表订阅或实际联系。中英以translationKey关联并保留语言。请求只含路径、公开内容标识、语言及白名单事件字段，不含查询串、片段、搜索词或表单文字。统计故障不阻塞导航。

同源`/site-events`由宿主精确代理至私有统计网关，网关再次校验域名、路径、事件、字段、体积和频率；不允许代理Umami其他API。服务、数据库、凭据和管理页面在私有运维环境，不能复制进本公开仓库。私有`/hub/site`沿用既有登录并设置本浏览器统计排除；其内容、审稿、译文和回执沿用原流程事实源。

首页宽屏以文字（雷达为独立页的紧凑入口）、单一精选项目区和宣言形成完整构图；高度以视口为参考，内容过长可自然增长。段落之间保留少量边缘与覆盖关联，原生滚动能停在中间、反向展开，不使用滚轮拦截、强制翻页或scroll-snap。窄屏/短视口回到自然排版，关闭或减少动态时取消黏附与退后效果。后续作品按原精选顺序进入，不另建内容源。

关于页首段以左侧姓名与本人选定的双语自述（每段一两句，保持原词句）、右侧彩色切角头像非对称呈现，头像采用银蓝全息细线切角框、剑形标志收在框内，关于页诗句及英文旁注撤掉，六身份融入头像两侧全息标注；自述按2026-10-24本人选定原文使用。以无边框、无投影、无缩放的全宽段落向上覆盖，接续社交和收藏；关于页暂不显示生产/革命宣言，首页宣言保留。收藏按认证证书、社区徽章、微信读书完整展示，不再切换或折叠。项目页恢复目录列表与桌面侧边预览，滚动及键盘焦点联动；关闭动态或窄屏回到自然列表。工具以普通段落和细分隔线展示原记录，撤外围大卡片。筛选、顺序及发布源不变。导航统一称项目（Projects），公开/projects路由和关联标识不变；首页移除工具段，主导航工具入口保留。内页栏目标题保留语义h1，不再视觉放大重复；正文与具体项目标题正常显示。博客与雷达不再维护重复栏目导航，博客分类、搜索和总数合并为单一工具栏。

浮卡无需单独配图或人工摘要：直接使用随HTML内嵌的公开正文，首次打开没有额外预览请求。交互模块通过modulepreload并行下载；路由接管后恢复已在文章上的悬停，鼠标移动事件也会补激活，避免必须移出再移入。挂载时的恢复帧随路由卸载取消。

悬停节奏按列表密度设置：首次停留150ms才触发、跨文章确认180ms，快速划过不会弹出；旧卡淡出再换内容，新卡以320ms柔和显现。位置跟随保持28ms时间常数，避免为了放慢显现而拖慢鼠标响应。

首页精选只显示一个栏目标题，主项目后自然接续另外两个精选，末尾一次总入口；旧selected-more为内部锚点。文章与项目底色拉开明暗，说明文字16px（手机项目15px）、行高1.85，注释12px。首页扫光、覆盖退后与循环演示收敛，标题流周期加倍，暂停及滑块不变；无强制翻页。该版已于2026-10-24发布。

关于页桌面姓名38–54px，头像与正文网格行垂直居中；英文短段落双栏16px/1.5行高，1280×720一屏完整阅读，手机自然单列。正文原词句不删改。

关于页中英原文集中于static/about-copy.js，前端与SSR共用；只修改此处，避免直接访问与切页显示不同文字。

剑形光标本体由网页绘制，直接使用pointer事件坐标（保留3px热点），不做插值或等待动画帧；外围准星单独缓动。仅在鼠标进入且资源加载成功后隐藏原生光标；输入、实际选字、滑块及禁用控件恢复原生形态；普通文字与标签悬停保持剑形。关闭/减少动态只停准星；触屏、高对比、窗口失焦或资源失败恢复原生光标。网页层不拦截点击，弹层沿用顶层渲染。
