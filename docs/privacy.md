# 公开仓库与私有运行环境的边界

这个仓库只保存公开网站页面、公开素材和独立内容适配模块。宿主可能还承载其他业务，但它们的源码、配置和数据不属于本站发布包。

## 不进入仓库

- 平台账号密码、API key、Token、cookie、SSH 私钥和证书私钥。
- 发布机器人配置、浏览器配置文件、运行账户清单与审稿批准台账。
- 宿主整体工程、私有业务路由、认证实现、nginx 和容器环境文件。
- 数据库、备份、运行日志、原始工作材料和操作取证。
- 实填服务器地址、私有入口探针与部署配置；这些设置留在仓库外。

`.gitignore`、`scripts/check_source.py` 和 CI 协同检查文件边界与常见凭据格式。扫描发现只打印文件名及规则，不打印匹配内容。它们不能证明所有未知格式的秘密都不存在，提交前仍要阅读 diff，按公开白名单选择文件。

## 不进入生产代码发布包

打包器只从选定 Git 提交读取明确的公开资源与适配模块；开发样例、文章、实时目录、文档和私有部署配置不打包。远端接收器再次校验路径及摘要，拒绝宿主入口、认证、环境和内容文件。

代码部署保存受管文件快照，回滚同样只恢复这些文件。原文章和作品目录由内容工具继续维护。维护权限、账号和密钥沿用已有私有环境，GitHub Actions 不保存它们。

旧 Astro 提交完整保留在历史标签。新增文件与历史文件分别核查；发现实际凭据时应先撤销凭据，再处理受影响历史，不能靠删除最新文件解决。
